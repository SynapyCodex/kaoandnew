# 💜 เว็บแอปพลิเคชันสำหรับฉันกับแฟน (Kao & New)

เว็บแอปพลิเคชันคู่รักสไตล์ **Minimalist White & Pastel Purple** ออกแบบพิเศษสำหรับคนรัก 2 คน ใช้งานร่วมกันได้ทั้งบนคอมพิวเตอร์และมือถือ

---

## 🌟 ฟังก์ชันหลักตามความต้องการ

1. **🎟️ หน้าตั๋วสิทธิพิเศษ (Love Tickets)**
   - ออกแบบสไตล์ **ตั๋วหนัง / คูปองวินเทจ** มีรอยปรุและบาร์โค้ด
   - สร้างบัตรตามใจ เช่น *บัตรตามใจ 1 วัน*, *บัตรนวดหลัง 30 นาที*, *บัตรห้ามโกรธ 1 ครั้ง*
   - กำหนดวันหมดอายุ หรือเลือกเป็น **"บัตรถาวร (ไม่มีวันหมดอายุ ♾️)"** ได้
   - มี **เอฟเฟกต์ฉีกตั๋วสมจริง (Cinema Ticket Tear Animation)** พร้อมพลุกระดาษ Confetti เมื่อกดใช้งาน
   - บัตรที่ถูกฉีกจะประทับตรา **"USED / ฉีกใช้งานแล้ว"** และย้ายไปแท็บบัตรที่ถูกใช้งานแล้ว
   - มีแท็บ **ประวัติ & การแก้ไข** สำหรับดูความเคลื่อนไหว

2. **📅 หน้าปฏิทิน & แจ้งเตือนวันสำคัญ (Shared Calendar)**
   - ปฏิทินแสดงผลรายเดือน ซิงค์ข้อมูลระหว่างเรากับแฟน
   - **ล็อกอัตโนมัติให้ทุกวันที่ 22 ของทุกเดือนเป็น "วันครบรอบของเรา 💕"** พร้อมสัญลักษณ์หัวใจ
   - บันทึกกิจกรรม เช่น วันส่งงาน, นัดเดท, วันเกิด
   - **ระบบแจ้งเตือนล่วงหน้า (Upcoming Reminders)** แสดงแบนเนอร์แจ้งเตือนกิจกรรมที่ใกล้ถึงวัน (เช่น ภายใน 3 วัน หรือวันนี้) เตือนทั้งคู่ช่วยกันดู

3. **💕 หน้าสิ่งที่ชอบ (Favorites Board)**
   - ตาราง 2 ฝั่ง: **สิ่งที่ฉันชอบ** เทียบกับ **สิ่งที่แฟนชอบ**
   - แยกหมวดหมู่: อาหารโปรด 🍣, เครื่องดื่ม/ของหวาน 🧋, สิ่งที่ไม่ชอบ/แพ้ 🚫, ของขวัญที่อยากได้ 🎁
   - ทั้ง 2 ฝ่ายสามารถเขียนสิ่งที่ตัวเองชอบ หรือแอบมาจดสิ่งที่อีกฝ่ายชอบไว้ได้

4. **🌧️ หน้าจุดนอย (Sulking Corner)**
   - โพสต์บอกความในใจเบาๆ ว่าวันนี้นอยอะไร
   - เลือกระดับความนอย (1 ถึง 5 หัวใจหัก 💔)
   - เมื่อแฟนง้อแล้วหรือหายแล้ว สามารถกด **"หายแล้วนะ 🥰"** เพื่อเปลี่ยนสถานะเป็นเคลียร์ หรือแก้ไข/ลบโพสต์ได้
   - แฟนสามารถกดส่งปุ่ม **"🫂 ส่งกอดให้แฟน"** และพิมพ์ข้อความง้อใต้โพสต์ได้

5. **🥺 หน้าจุดระบายแฟน (Vent Corner)**
   - โพสต์ความรู้สึกพร้อม Emotion Tags:
     - 🥺 **งอน**
     - 😡 **โกรธ**
     - 🌧️ **นอย**
     - 😢 **เสียใจ**
     - 🥺👉👈 **อยากให้มาง้อ**
     - 💬 **อยากคุยกัน**
     - 😤 **ชิชิงอน (งอนเบาๆ)**
   - ช่องระบุรายละเอียดสิ่งที่อยากให้แฟนง้อ (เช่น อยากให้โทรหา, อยากให้กอด, พาไปกินไอติม)
   - มีช่องให้แฟนพิมพ์ข้อความตอบกลับและปรับความเข้าใจ

6. **💖 หน้าสถานะแฟน (Couple Status Dashboard)**
   - แสดงโปรไฟล์ของฉันและแฟน พร้อมตัวนับวันคบกัน (คบกันมาแล้ว XXX วัน)
   - ตัวนับวันครบรอบประจำเดือนครั้งถัดไป (ทุกวันที่ 22)
   - อัปเดตสถานะอารมณ์แบบเรียลไทม์:
     - *อารมณ์ดี ☀️, รักแฟนที่สุด 🥰, คิดถึงแฟนมาก 💖, งอน 🥺, ชิชิงอน 😤, นอย 🌧️, โกรธ 😡, เสียใจ 😢, อยากให้มาง้อ 🥺👉👈, อยากคุยกัน 💬*
   - พิมพ์ข้อความ Note สั้นๆ บอกแฟน
   - แก้ไขชื่อเล่น, เลือก Avatar อิโมจิ, วันเริ่มคบ และคำคมประจำใจได้

## 🚀 วิธีเปิดใช้งาน

### 1. รันระบบ (Server & Frontend พร้อมกัน)
```bash
npm run dev
```
หรือรันเฉพาะเซิร์ฟเวอร์ที่ Build แล้ว:
```bash
npm start
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:3001` (หรือ `http://localhost:5173`)

### 2. วิธีใช้งานพร้อมกัน 2 เครื่อง (คอมพิวเตอร์ & โทรศัพท์มือถือ)
เมื่อคอมพิวเตอร์และมือถือเชื่อมต่อ WiFi เดียวกัน สามารถเข้าผ่าน IP ของคอมพิวเตอร์ได้ เช่น:
```
http://[IP-เครื่องของคุณ]:3001
```
*(เช่น `http://192.168.1.50:3001`)* โดยฝ่ายหนึ่งเลือกสลับเป็น **"ฉัน"** และอีกฝ่ายเลือกเป็น **"แฟน"** ข้อมูลจะบันทึกและซิงค์ตรงกันอัตโนมัติ

## 🎨 โครงสร้างเทคโนโลยี (Tech Stack)
- **Frontend**: React 19, Tailwind CSS v4, Lucide Icons, Canvas-Confetti, Vite 8
- **Backend**: Node.js, Express, REST API
- **Database**: Persistent JSON Storage (`server/data/db.json`)
